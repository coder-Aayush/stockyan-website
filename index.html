Windows blocked the app from opening?

Windows may block new apps it doesn't recognise yet. To run StockYan:

  1. Right-click StockYan (or finnepal.exe) → Properties → tick Unblock → Apply.
  2. If it still won't open: open Windows Security → App & browser control → Smart App Control settings and turn it Off, then launch again.

This happens because the app isn't code-signed yet, but it's safe to run.
