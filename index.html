Windows blocked the app from opening?

Windows may block new apps it does not recognise yet. To run StockYan:

  1. Right-click StockYan (or finnepal.exe) → Properties → tick Unblock → Apply.
  2. If it still will not open: open Windows Security → App & browser control → Smart App Control settings and turn it Off, then launch again.

This happens because the app is not code-signed yet, but it is safe to run.
